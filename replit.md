# Uebung1 - ABK C++ Kurs

## Overview
This is a C++ learning repository for the ABK C++ course ("ABK-C++-Kurs"). It contains basic C++ exercises demonstrating fundamental concepts like console output and file I/O.

## Project Structure
- `hallo.cc` - Simple "Hello World" program demonstrating basic output
- `summieren.cc` - Program that reads number pairs from `daten.txt`, sums each pair, and writes results to `datensumme.txt`
- `stichprobe.cc` - Program that reads `datensumme.txt` and calculates mean, variance, and standard deviation
- `stichprobe2.cc` - Program that divides data into groups of 9, calculates group statistics, and outputs to files
- `daten.txt` - Data file containing number pairs for processing
- `datensumme.txt` - Output file generated by summieren.cc (contains sums)
- `mittelwerte.txt` - Output file generated by stichprobe2.cc (contains group means)
- `varianzen.txt` - Output file generated by stichprobe2.cc (contains group variances)
- `Makefile` - Build configuration for compiling the C++ programs
- `run.sh` - Script to build and run all programs

## Programs

### hallo
A simple program that prints "Hallo Welt!" to the console.

**Compile:** `make hallo`  
**Run:** `./hallo`

### summieren
Reads pairs of numbers from `daten.txt`, calculates the sum of each pair, and writes the results to `datensumme.txt`.

**Compile:** `make summieren`  
**Run:** `./summieren`

### stichprobe
Reads the sums from `datensumme.txt` (generated by summieren) and calculates:
- Mean of all 234 values
- Variance
- Standard deviation

**Compile:** `make stichprobe`  
**Run:** `./stichprobe`

**Note:** You must run `./summieren` before running `./stichprobe` since stichprobe depends on the output file from summieren.

### stichprobe2
Reads `datensumme.txt` and performs group-based statistical analysis:
- Divides the 234 values into groups of 9 (26 groups total)
- Calculates mean and variance for each group
- Writes group means to `mittelwerte.txt`
- Writes group variances to `varianzen.txt`
- Outputs the mean of means and mean of variances to console

**Compile:** `make stichprobe2`  
**Run:** `./stichprobe2`

**Note:** You must run `./summieren` before running `./stichprobe2` since it also depends on `datensumme.txt`.

## Build Instructions

### Build and run all programs:
```bash
./run.sh
```

### Compile all programs:
```bash
make all
```

### Compile individual programs:
```bash
make hallo
make summieren
make stichprobe
make stichprobe2
```

### Clean build artifacts:
```bash
make clean
```
